# MVP 1.0 integrado

O pipeline FastAPI e os contratos anteriores foram preservados. A nova loja utiliza o catálogo normalizado PostgreSQL com ponte para o ID de SKU legado. As migrations 000/001/002 são aditivas e a inicialização é repetível.

O shell React está separado em catálogo, perfil, fitting e comércio. A comparação declarada é calculada no backend; o frontend apenas exibe os motivos/estado. A foto continua no pipeline de landmarks original, com privacidade, qualidade e renderer 2D.

A referência orienta a composição escura com ficha lateral, comparação simultânea desktop e versão focada mobile. As bases naturais são arte genérica em 2D; o avatar ilustrado atende personalização, categorias e looks. Não há simulação física ou geração fotorrealista individual configurada.

Consulte README.md para execução e contratos, MANUTENCAO.md para responsabilidades, VALIDACAO.md para verificações e ASSETS_VISUAIS.md para a origem das artes.
