==================================================
REGRA MUITO IMPORTANTE:
ROUPA BASE / ROUPA NEUTRA
==================================================

Atualmente o avatar utiliza uma roupa neutra/base para que ele não fique totalmente exposto.

Porém existe um problema:

quando o usuário seleciona uma peça nova, essa peça aparece POR CIMA da roupa neutra.

Não quero isso.

Quero mudar completamente essa lógica.

==================================================
COMPORTAMENTO ESPERADO
==================================================

A roupa neutra/base deve funcionar apenas como fallback.

Se nenhuma peça estiver selecionada naquela região:
a base neutra pode aparecer.

Mas se o usuário selecionar uma peça:
A BASE NEUTRA DESSA REGIÃO DEVE DESAPARECER.

A peça escolhida deve substituir visualmente a base.

==================================================
EXEMPLOS
==================================================

SE O USUÁRIO ESCOLHER APENAS CAMISETA:

Quero:
- apenas a camiseta vestida no tronco.

Não quero:
- camiseta por cima de outra camiseta neutra.

SE O USUÁRIO ESCOLHER APENAS CALÇA:

Quero:
- apenas a calça na parte inferior.

Não quero:
- calça sobre outra roupa existente.

SE ESCOLHER:

camiseta + calça

Quero:
- camiseta selecionada;
- calça selecionada;
- nenhuma roupa neutra aparecendo por baixo nessas regiões.

==================================================
SUBSTITUIÇÃO DE PEÇAS
==================================================

Se o usuário trocar uma camiseta por outra:

- saias;

- outras categorias.

Trocar calça não deve remover a camiseta.
